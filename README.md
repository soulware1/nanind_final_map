The save data for [-nan(ind)](https://www.roblox.com/games/116097661017996/nan) as it was on 10-10-2026

placetime: unix timestamp of placement

position: self-explanatory

color: hex code for the color of the stud

material: roblox enum for the material https://create.roblox.com/docs/reference/engine/enums/Material

placer: either a roblox id or a display name
